# Genealogger

Genealogger is a client-side JavaScript web application built on the DEER
(Data Encoding and Exhibition for RERUM) conventions for managing
genealogical data as evidence-backed entities and annotations. It is a
static web application (no build step) that connects to RERUM services for
storage and uses ES6 modules with custom web components.
